How do I get my Strava export?
  1. On strava.com (not the app), open Settings → My Account.
  2. Under Download or Delete Your Account, choose Get Started, then Request Your Archive.
  3. Strava emails you a link to a .zip, usually within a few hours. Drop that zip straight in here; there's no need to unzip it.

      How it works

      1. Reads every GPS file (FIT, GPX, TCX) and leaves out virtual rides, gym sessions and anything else without a real route.
      2. Cleans the tracks: removes GPS glitches and breaks lines wherever the signal dropped, so nothing gets drawn straight across the map.
      3. Finds your home turf. Activities are grouped by area and the busiest area wins, so one holiday abroad doesn't shrink everything to a dot.
      4. Stacks your routes. Each activity is drawn once and the layers add up. Brightness is how many separate trips used a road, on a log scale so quiet lanes still show.

      The processing code is the same open-source Python that runs on the command line, compiled to run in your browser with Pyodide. The first run downloads about 15 MB, which your browser then caches.
